책장 넘기기 원리

오른쪽 페이지를 눌러 왼쪽으로 끌어 보세요. P 는 누른 높이의 페이지 오른쪽 끝(손가락이 잡고 끄는 끝), F 는 지금 손가락입니다.

180°

0° 는 아직 안 접힌 상태, 180° 는 완전히 접혀 넘어온 상태입니다. 밀어 보면 2 가 접힌 선을 축으로 들려 넘어가며 뒷면 3 으로 바뀝니다.

레이어

  • 1왼쪽 페이지
  • 2넘기는 페이지 앞면
  • 3넘기는 페이지 뒷면
  • 4밑에 깔린 다음 페이지

점

  • P누른 높이의 페이지 오른쪽 끝
  • F지금 손가락
  • A2 의 오른쪽 위 모서리
  • A′3 의 왼쪽 위 모서리를 둘 자리

그리는 순서

  1. P 와 F 를 잇고, 그 가운데에서 직각으로 그은 선이 접힌 선
  2. 2 는 접힌 선까지만 남기고 지운다. 지운 자리로 4 가 보인다
  3. 3 의 왼쪽 위 모서리를 A′ 에 두고, 지금 위치(세로)에서 딱 2α 돌린다. 그다음 접힌 선 너머(P 쪽)를 잘라 F 쪽만 남긴다

지금 각도

끈 방향이 수평에서 기운 각도
0°
접힌 선이 세로에서 기운 각도
0°

0°

왜 두 배?

갈색 점선(원래 끝)에서 빨간 접힌 선까지 α. 접으면 점선이 접힌 선 너머로 넘어가 갈색 실선이 되는데, 접기는 접힌 선 기준 대칭이라 접힌 선에서 갈색 실선까지도 똑같이 α. 그래서 점선에서 갈색 실선까지 2α 이고, 3 은 지금 위치에서 딱 2α 돌려야 갈색 실선에 겹친다.

세 선이 만나는 점에서, 아래로 끌면 위쪽 점선, 위로 끌면 아래쪽 점선(P 쪽)에서 잰다. 어느 쪽이든 2α.

정리

  • 접힌 선은 P 와 F 의 한가운데를 P → F 와 직각으로 지난다.
  • P → F 가 가로에서 α 기울면, 직각인 접힌 선은 세로에서 α 기운다.
  • 원래 끝(점선) → 접힌 선 α, 접힌 선 → 넘어간 끝(실선) α. 접기는 대칭이라 둘이 같다.
  • 그래서 3 은 지금 위치(세로)에서 딱 2α 돌린다. 1배만 돌리면 접힌 선과 나란해질 뿐 갈색 실선에 안 겹친다.
  • 3 의 왼쪽 위 모서리는 A′, 돌린 뒤 접힌 선 너머(P 쪽)는 잘라 낸다. 2 도 접힌 선까지만 남긴다.
