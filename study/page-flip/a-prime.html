A′ 구하고 3 페이지 돌리기

책 오른쪽 맨 위 모서리 A 를 접힌 선 기준으로 넘긴 자리 A′ 를 중학교 수학으로 구하고, 3 페이지를 A′ 에 두고 몇 도 돌릴지 CSS 로 적는 법까지 한 단계씩 봅니다. "다음" 을 누르며 보세요.

    지금 숫자

    코드로 옮기면 (주석 숫자는 예시 값)

    // P, F 는 { x, y } 좌표. A 는 책 오른쪽 맨 위 { x: 1000, y: 0 }
const dx = F.x - P.x;                    // −240  P→F 가로
const dy = F.y - P.y;                    // 180   P→F 세로
const len = Math.hypot(dx, dy);          // 300   피타고라스
const cosA = -dx / len;                  // 0.8   cos α = 가로 ÷ 길이
const tanA = dy / -dx;                   // 0.75  tan α = 세로 ÷ 가로

const M = { x: (P.x + F.x) / 2, y: (P.y + F.y) / 2 };   // (880, 290)
const Sx = M.x - M.y * tanA;             // 662.5  접힌 선이 맨 위에 닿는 점 S 의 x
const AS = A.x - Sx;                     // 337.5
const AH = AS * cosA;                    // 270    A 에서 접힌 선까지 거리

const A2 = {                             // A′ = A 에서 P→F 방향으로 AH 의 두 배
  x: A.x + 2 * AH * (dx / len),          // 568
  y: A.y + 2 * AH * (dy / len),          // 324
};

const alpha = Math.atan(tanA) * 180 / Math.PI;   // 36.9  접힌 선 각도 (= α, 도)
// A′ 에 두고, 접힌 선 각도 × 2 만큼 돌린다. 아래로 끌면 반시계라 −
page3.style.transformOrigin = '0 0';
page3.style.transform = `translate(${A2.x}px, ${A2.y}px) rotate(${-2 * alpha}deg)`;
