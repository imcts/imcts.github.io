3 페이지 회전 각도

"다음" 을 누르며 한 단계씩 보세요. 아래 슬라이더로 끄는 각도를 바꾸면 모든 각이 같이 바뀝니다.

1 / 6

α = 30°3 페이지 회전 = 60°

    각도를 어디서 재나

    끈 각도 α
    P 에서 — 가로선과 회색 점선(P → F) 사이
    접힌 선 α
    X 에서 — 점선(오른쪽 끝)과 빨간 접힌 선 사이
    넘어간 끝 α
    X 에서 — 빨간 접힌 선과 갈색 실선 사이
    3 페이지 2α
    X 또는 A′ 에서 — 세로와 갈색 실선 사이

    정리

    • 접힌 선은 P 와 F 의 한가운데를 P → F 와 직각으로 지난다.
    • P → F 가 가로에서 α 기울면, 직각인 접힌 선은 세로에서 α 기운다.
    • X 에서 점선 → 접힌 선 α, 접힌 선 → 갈색 실선 α. 접기는 접힌 선 기준 대칭이라 둘이 같다.
    • 그래서 점선 → 갈색 실선은 2α. 3 페이지 왼쪽 끝은 세로로 서 있다가 갈색 실선에 겹쳐야 하니, 지금 위치에서 딱 2α 돌린다.
    • 위로 끌 때는 X 아래쪽 점선(P 쪽)에서 재면 똑같이 2α 다.
    • 3 은 왼쪽 위 모서리를 A′ 에 두고 돌린 뒤, 접힌 선 너머(P 쪽)를 잘라 낸다.
